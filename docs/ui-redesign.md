# XSTAR 播放器 · 单页极简重设计（v2 方案）

> 状态：**已实施（WPF）**
> 可交互原型：`docs/ui-redesign-prototype.html`（支持亮/暗切换、封面实时取色、队列/歌词/设置/音乐库）
> 目标：将现有"顶栏 + 播放区 + 队列/歌词"的复合界面，收敛为**单页极简播放器**——
> 页面只保留 **播放控制 / 播放列表 / 歌词** 三件事，其余控制全部收进 **设置**。
> 视觉上提供 **亮 / 暗双主题并跟随系统**，主色 **按封面自动取色（动态主题）**。

---

## 1. 设计目标与原则

| 原则 | 说明 |
| --- | --- |
| 单页、无跳转 | 全应用只有一个主页面；库管理、外观、在线能力等通过「设置」覆盖层完成。 |
| 主页面只做三件事 | 播放控制、播放列表、歌词展示。没有搜索框、视图下拉、在线按钮、扫描按钮。 |
| 内容优先 | 默认视口把注意力给封面与当前歌曲；列表与歌词是"第二层"，可折叠/可调高。 |
| 主色随内容流动 | 强调色由当前封面推导，整页氛围随歌曲变化，形成"每首歌一个界面"的沉浸感。 |
| 系统一致性 | 亮/暗跟随系统；支持高对比度、减少动画、Per-Monitor DPI 与系统字体回退。 |
| 可渐进实施 | 现有功能（收藏/历史/播放列表/歌词/在线搜索/扫描）不删除，只是重新归类入口。 |

**与现状的差异（重要）**

- 移除主界面上的：视图选择下拉（歌曲/专辑/艺术家…）、搜索框、在线搜索按钮、文件夹/扫描按钮、EQ 入口。
- 移除独立的"绿色播放键 + 靛蓝强调"双色体系，改为**单一动态强调色**（播放键使用该色）。
- 现有 6 种浏览视图（歌曲/专辑/艺术家/收藏/最近/播放列表）迁移到设置内的「音乐库」，或可选地放入独立"库"覆盖层（见 §11 待确认）。

## 2. 信息架构与导航

```text
主窗口（长方形单页）
├── 顶部栏（48px）
│   ├── 左：品牌标识
│   └── 右：音乐库入口 + 设置入口 + 窗口按钮
└── 舞台区（长方形，内容居中）
    ├── 专辑页面（默认）—— 居中封面 + 曲目信息
    ├── 播放列表页面     —— 居中队列列表
    ├── 歌词页面         —— 居中歌词
    └── 悬浮控制条       —— 居中、**透明融入背景**，覆盖在以上页面上方，始终可见
        ├── 单行居中：播放模式 · 音量 · 上一首 · 播放暂停 · 下一首 · 播放列表 · 歌词
        └── 进度条

覆盖层（Overlay，覆盖主窗口，可按 Esc 关闭）
├── 音乐库     —— 顶栏图标直达：歌曲/专辑/艺术家/收藏/最近/播放列表
└── 设置
    ├── 音乐库   （文件夹、扫描、库浏览入口）
    ├── 外观     （主题模式、强调色来源、动效、唱片：旋转 / 大小 / 速度）
    ├── 播放     （默认模式、音量、淡入淡出）
    ├── 歌词     （在线歌词开关、样式、缓存清理）
    ├── 在线     （Jamendo client_id、在线搜索开关、下载目录）
    └── 关于     （版本、开源许可、BASS 许可）
```

- **无底部导航、无侧边栏常驻**；主界面为"长方形页面 + 居中悬浮控制条"。
- 顶栏左侧品牌、右侧两个入口图标：**音乐库** 与 **设置**（以及窗口按钮）。
- **页面切换（播放列表 / 歌词）做成图标按钮，放进悬浮控制条**，不再占用顶栏。
- 所有"设置类"操作即时生效（无"确定/取消"按钮），仅有"关闭"。

## 3. 主界面布局

> 布局要点：窗口为**一个长方形页面**；**专辑页面居中**（封面 + 曲目信息），**控制条居中并悬浮在专辑页面上方**；
> **播放列表 / 歌词切换作为图标按钮放在控制条里**，点击后在长方形页面中展示对应页面；
> 控制条**不分栏、单行居中**，整块**透明无底板**，直接融入背景。
>
> **实施后调整（2026-09）**：已按需求**取消专辑封面**——专辑页只保留居中的歌曲信息（标题 / 艺术家·专辑 / 音质徽标 / 收藏）+ 动态取色氛围背景；封面仍用于取色。

### 3.3 尺寸与结构

| 区域 | 规格 |
| --- | --- |
| 窗口默认 | **900 × 600（横向长方形）**；最小 680 × 480；**支持拖拽自由缩放**（受限在 96vw / 92vh 内） |
| 顶栏 | 48px；左品牌 / 右侧"音乐库 + 设置 + 窗口按钮" |
| 专辑页面 | 铺满舞台区，封面**水平垂直居中**；封面随窗口自适应（约 140–300px），圆角 20px |
| 歌曲信息 | 叠加在封面**正中**；**默认仅显示歌名与歌手，无底色、背景全透明**；**鼠标移入封面时淡入其余信息**（音质徽标 / 收藏，约 220ms）；文本带阴影保证在封面上可读 |
| 控制条 | **居中悬浮、透明无底板**（无背景/边框/阴影），宽 `min(680px, 100%−40px)`，底部距 22px |
| 控制条内容 | 单行居中：播放模式 · 音量 · 上一首 · 播放暂停 · 下一首 · 播放列表 · 歌词 |
| 页面切换 | 控制条内两个**图标按钮**（列表 / 歌词）；可为空（空 = 专辑页面） |
| 播放列表页 | 列表限宽 900px 居中；顶部右侧放 排序 / 清空；底部预留控制条高度 |
| 歌词页 | 歌词限宽 760px 居中；当前行强调色高亮 |

### 3.4 顶栏与窗口

- **采用自定义标题栏（`WindowChrome`）**，左右两端布局：
  - 左：品牌 `✦ XSTAR`。
  - 右：`音乐库` 图标、`设置` 图标、最小化/最大化/关闭。
- 窗口可自由缩放：封面尺寸、控制条宽度、列表/歌词宽度都随窗口自适应（WPF 中使用 `Viewbox`/比例布局或 `SizeChanged` 调整）。
- 页面切换图标位于控制条内，顶栏不承载切换。
- 顶栏整条为拖拽区域，仅图标/按钮区域可点击。
- 顶栏不显示"本地音乐库"、曲库统计等次要信息（统计移入设置）。

## 5. 主题系统：亮 / 暗 + 动态取色

### 5.1 三层 Token 架构

```text
Primitives（原始值）        Semantic（语义）              Component（组件）
中性色阶 N0..N1000    →    bg.canvas / bg.surface   →    WindowBackground
动态强调色阶 accent.*       text.primary / secondary       QueueRow.Background
                           border.* / overlay.*            PlayButton.Background
                           accent.base / subtle / glow
```

- 亮、暗各一份 `ResourceDictionary`（`Themes/Light.xaml`、`Themes/Dark.xaml`），运行时切换合并字典。
- 动态强调色由运行时生成器写入一组**不冻结**的 `SolidColorBrush` 资源，绑定自动刷新。
- 组件只引用语义 Token，不直接写死色值。

### 5.2 颜色语义对照（初稿）

| Semantic Token | Dark | Light |
| --- | --- | --- |
| `bg.canvas` | `#0B0C10` | `#F6F7FB` |
| `bg.surface` | `#14161D` | `#FFFFFF` |
| `bg.surfaceElevated` | `#1B1E27` | `#FFFFFF` |
| `bg.sunken` | `#0E1016` | `#EEF0F6` |
| `text.primary` | `#F4F6FA` | `#17181C` |
| `text.secondary` | `#A6ADBD` | `#555B68` |
| `text.muted` | `#6E7686` | `#8A90A0` |
| `border.subtle` | `#FFFFFF14` | `#E4E7EF` |
| `border.default` | `#FFFFFF1F` | `#D8DCE7` |
| `border.strong` | `#333A4A` | `#C2C7D6` |
| `overlay.scrim` | `#000000A6` | `#1A1B2499` |
| `accent.base` | 动态 | 动态 |
| `accent.subtle` | accent @14% | accent @12% |
| `accent.glow` | accent @45% | accent @30% |
| `text.onAccent` | 自动（黑/白） | 自动（黑/白） |
| `state.danger` | `#F87171` | `#DC2626` |
| `focus.ring` | accent @80% | accent @80% |

### 5.3 封面取色算法

```text
封面图片
  → 缩放到 48×48
  → 转 HSL，过滤近灰 (S < 0.15) 与近黑/近白 (L < 0.10 或 L > 0.95)
  → 按色相分桶（24 桶），权重 = 像素数 × 饱和度
  → 取权重最高桶，回算平均 H / S / L 作为种子色
  → 归一化：
       accent.base    : S 夹到 0.45–0.85；Dark L 0.58–0.72 / Light L 0.42–0.56
       accent.hover   : base 亮度 +0.06
       accent.pressed : base 亮度 −0.06
       accent.subtle  : base 透明度 12%–14%
       accent.glow    : base 透明度 30%–45%
       text.onAccent  : 与白对比 ≥ 4.5:1 用白，否则用近黑
       视差渐变背景    : base 压暗/提亮后与 bg.canvas 融合
  → 无封面 / 过滤后无有效色 → 回退品牌色 #6E8BFF
```

- 取色在后台线程执行，按 `artKey` 缓存，避免重复计算。
- 切歌时强调色**交叉淡入 ~400ms**，同时更新光晕、进度条填充、播放键、选中高亮、歌词当前行。
- 无障碍兜底：高对比度模式或用户选择"固定品牌色"时锁定为 `#6E8BFF`。

### 5.4 跟随系统

- 读取 Windows 应用主题（注册表 `AppsUseLightTheme`），默认 `跟随系统`，并监听变化实时切换。
- 主题切换时对背景/文字做 ~200ms 淡入，避免闪烁。

## 6. 设计 Token

### 6.1 字体

| 用途 | 字体 | 说明 |
| --- | --- | --- |
| 界面 | `Segoe UI Variable Text, Segoe UI, Microsoft YaHei UI` | 中英混排回退；替换现有 Righteous/Poppins（拉丁专用、不含中文） |
| 数字/时间 | 同界面字体，`NumeralAlignment = Tabular` | 进度时间不跳动 |
| 品牌字 | 仅 "XSTAR" 字样可选用展示体（如 Righteous） | 可选，不用于正文 |

| 层级 | 字号/行高 | 字重 |
| --- | --- | --- |
| Display（曲名） | 30 / 36 | SemiBold |
| H1（设置标题） | 20 / 28 | SemiBold |
| Body | 14 / 20 | Regular |
| BodySm（列表） | 13 / 18 | Regular |
| Caption | 12 / 16 | Regular |
| Micro（时间/徽标） | 11 / 14 | Medium |

### 6.2 间距 / 圆角 / 阴影

| 类别 | 值 |
| --- | --- |
| 间距阶 | 2, 4, 6, 8, 12, 16, 20, 24, 32, 40 |
| 圆角 | sm 6 / md 10 / lg 14 / xl 20 / pill 999 |
| 阴影 | 深色以边框 + 表面提亮为主；仅封面与主播放键使用强调色辉光 |

### 6.3 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 悬停 / 按下 | 120ms | EaseOut |
| 面板切换 / Tab / 展开 | 200ms | EaseOut |
| 主题 / 强调色交叉淡入 | 400ms | EaseOut |
| 封面切换 | 300ms 淡入 + 轻微缩放 | EaseOut |
| 歌词当前行 | 200ms | EaseOut |

- 精简动效模式或系统"减少动画"开启时，跳过非必要动画，直接呈现终态。

## 17. 旋转光碟（Vinyl Disc）

播放页中央新增一枚旋转黑胶光碟（逻辑尺寸 340，经 `DiscScale` 放大 1.2 → 视觉约 408，置于歌名信息**下层**，歌曲信息居中覆盖其上）：

- **纯矢量绘制**：径向渐变盘身 + 对角高光 + 中心标签 + 轴心孔；盘身带 `DropShadowEffect` 投影。
- **纹路**：启动时用 `BuildGrooveImage(340)` 生成 `DrawingImage`——在标签半径到外沿之间以 ~1.35px 间距绘制大量细同心圆（透明度/粗细随机化），并随机插入更宽的深色"间隔带"，再裁剪到盘面圆形，得到密集、拟真的黑胶纹理。
- **中心标签纹理**：`BuildLabelTextureImage(140)` 在标签上叠加 ~1.05px 间距的细同心圆（透明度 6%–12%）与边缘暗角，得到带压纹/质感的中标，随盘一起旋转。
- **布局**：光碟与 `NowPlayingInfo` 为同级层，光碟在下、信息在上，均垂直居中（同 `Margin` 底部 72 对齐圆心）；歌名/副标题加轻量 `DropShadowEffect` 保证覆盖光碟时的可读性。
- **封面（图片碟）**：当歌曲有封面/歌手图片时，用覆盖整盘的圆形 `ImageBrush`（`UniformToFill`）把图片作为碟面，隐藏强调色中心标签，并在图片上加一层径向暗角遮罩（中心 `#73000000` → 透明）以保证居中文字可读，得到"图片碟"效果；无封面时回退为强调色径向渐变中心标签（压暗至 78% → 46%），**随主题切换实时更新**（`OnThemeChanged` 中重算，修复切换主题时光碟颜色不跟随的问题）。
- **图片来源**：`ArtworkLoader.LoadForSong(song)` 优先取内嵌/专辑封面（`song.ArtworkPath`），否则在歌曲所在目录查找同名封面（`cover` / `folder` / `album` / `front` / `artist` / `artwork`）或与歌曲同名的图片，最后回退到目录内任意一张图片；强调色取色同样走该入口。
- **旋转**：`RotateTransform` + `DoubleAnimation`（默认 26s/圈，`RepeatBehavior.Forever`）经 `AnimationClock` / `ClockController` 控制；播放时 `Resume`、暂停时 `Pause`，状态在 `UpdateProgress`（250ms）中同步。速度改变时按新周期重建时钟。
- **可调参数**：设置 → 外观 → 唱片，提供 `唱片旋转` 开关、`光碟大小`（80%–150%，写入 `DiscScale`）与 `转动速度`（4–60 秒/圈）滑块，实时生效并持久化（`DiscSize` / `DiscSpeed`）。
- **可见性**：无选中歌曲时隐藏；`精简动效` 或 `唱片旋转` 设置关闭时不旋转（设置 → 外观 → 唱片）。

## 18. 窗口透明度

设置 → 外观 → 窗口，提供 `窗口透明度` 滑块（0%–100%，数值越大越透明），内部换算为 `Window.Opacity = 1 - 透明度`（整个窗口含背景与标题栏一起透出桌面），实时生效并持久化为 `AppState.WindowOpacity`，启动时恢复。

- **关键**：透明度 >0（即 `Opacity<1`）时把 `WindowBackdropType` 切到 `None`（`ApplyBackdropForOpacity`），否则系统背板（Mica/Acrylic/Tabbed）由 DWM 绘制、不受 WPF `Opacity` 影响，窗口仍会显示为一块不透明表面；回到 0%（`Opacity=1`）时还原为当前主题预设的背板。主题切换（`OnThemeChanged`）后重新套用该规则。
- **透明底色**：同一处把窗口 `Background` 设为 `Transparent`，避免背板关闭时窗口露出主题实心底色（浅色主题下是纯白）——这样窗口只有内容本身，低于 100% 时桌面可直接透出。100% 时材质仍由 Mica/Acrylic 背板提供，视觉不变。
- **0% 完全隐藏**：≤0.1% 时不再依赖 `Opacity`（WPF 在 `Opacity=0` 时仍会画出窗口默认底色，浅色主题下是纯白块），而是直接 `Hide()` 窗口；由托盘菜单「显示主窗口」或双击托盘图标恢复（`ShowMainWindow` 会 `Show()` 并把不透明度调回 100%，设置面板打开时刷新其滑块）。
