| 项目 | 内容 |

## 2. 产品概述

XSTAR（Windows 版）是一款本地优先的 Windows 桌面音乐播放器。用户主动添加一个或多个音乐文件夹，应用递归扫描其中的常见音频文件并建立本地音乐索引，提供沉浸式播放、队列管理、歌词与封面展示能力。

产品强调本地隐私、播放稳定性和现代化桌面体验：无需登录、不上传文件、不依赖网络即可播放，不修改用户原始音乐文件。

未来版本规划：均衡器（EQ）、在线搜歌与下载、歌手/专辑图片补充。所有在线能力默认关闭、由用户主动触发，可随时在设置中整体关闭。

## 3. 产品目标

### 3.1 初版目标（MVP）

- 添加、移除与持久化多个音乐文件夹（本地路径）。
- 递归扫描指定文件夹及其子目录中的常见音频文件。
- 单页界面：上方为播放/专辑区域，下方为播放列表，可切换为歌词视图。
- 播放、暂停、上一首、下一首、进度拖动、播放模式切换。
- 顺序播放、随机播放、单曲循环。
- 解析标题、歌手、专辑、时长、编码、码率、采样率、位深、声道与内嵌封面，并做音质分级。
- 展示内嵌专辑封面；缺失时显示默认封面。
- 桌面集成：媒体键、任务栏播放缩略图、系统托盘、重启后恢复播放现场。
- 音乐库按歌曲/专辑/艺术家浏览与搜索（单页内通过面板/弹层完成）。

### 3.2 第二阶段目标

- 歌词：本地同名 `.lrc` → 已缓存歌词 → LRCLIB 在线歌词（多候选选择），当前行高亮与自动滚动。
- 封面补充：用户主动触发 iTunes / MusicBrainz 在线封面与歌手/专辑图片，候选选择后落本地缓存。
- 目录变更自动增量扫描（FileSystemWatcher）。

### 3.3 后续版本目标（P2）

- 均衡器：10 段图示 EQ + 前置增益 + 预设，仅作用于播放输出。
- 在线搜歌与下载：第三方公共聚合 API，下载到用户指定目录并自动入库、去重。
- 自定义播放列表、收藏视图与最近播放。

### 3.4 非目标（初版）

- 音频剪辑、转码与标签编辑。
- 修改、移动或删除用户原始文件。
- 云账号、云同步。
- 系统级（全局）均衡器。
- 卡拉 OK、投屏、一起听（Android 版独有能力，暂不移植）。

## 4. 用户场景

| 场景 | 用户目标 |
| --- | --- |
| 首次使用 | 添加一个或多个音乐目录并建立音乐库 |
| 日常播放 | 启动后恢复上次现场并继续播放 |
| 音乐浏览 | 按歌曲、专辑或艺术家浏览本地音乐 |
| 队列管理 | 查看当前播放列表、双击切歌、移除与清空 |

## 6. 页面与导航

应用为单窗口、单主页面，无页面跳转，无底部导航。导航通过顶部工具栏控件与侧弹层完成。

```text
┌──────────────────────────────────────────────────────────┐
│ 窗口标题栏（自定义）：XSTAR   [最小化][最大化][关闭]          │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 工具栏：库筛选 ▾ | 搜索框 | ➕文件夹 | ⟳扫描 | EQ | ⚙设置 │ │
│ └──────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────┬─────────────┐ │
│ │ 专辑/播放区：封面(大图) + 标题/歌手/专辑   │  （歌词时）  │ │
│ │ 音质徽标 + 进度条 + 控制条（模式/上下/播放）│             │ │
│ └────────────────────────────────────────┴─────────────┘ │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 底部面板：Tab[播放列表 | 歌词]         ♥ ❚排序 ▸ …      │ │
│ │  （播放列表 或 歌词滚动视图）                            │ │
│ └──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

主要弹层：
- 音乐库筛选面板（全部歌曲/专辑/艺术家 + 文件夹管理入口）。
- 均衡器面板（P2）。
- 设置面板（文件夹、扫描、在线开关、EQ、主题）。
- 在线搜歌面板（P2）。

## 7. 数据与行为规则

- 应用只处理用户添加的文件夹；路径与配置保存于 `%APPDATA%\XstarMusic\settings.json`。
- 歌曲主键由文件完整路径的 SHA-256 摘要前 8 字节生成（与 Android 版同规则，便于未来互通）。
- 重新扫描有效目录集合为“音乐文件夹 ∪ 在线下载目录（P2）”。
- upsert 前读取旧记录，保留收藏、播放次数与最近播放时间。
- Queue 是当前播放列表（本次会话内代表源列表），可持久化为播放现场。
- 顺序模式在队列末尾停止；随机模式随机并循环；单曲循环重复当前歌曲。
- 在线封面/歌词仅在用户主动操作后请求；相关开关关闭时不在任何入口显示在线操作。
- 在线下载的音频写入用户选择目录，`onlineId` 标记来源，重新扫描不删除、不重复入库。
- 播放现场持久化使用约 1 秒 debounce，避免高频写入。

## 8. 非功能需求

### 8.1 性能

- 文件扫描、元数据解析与封面提取在后台线程执行，不阻塞 UI。
- 万级曲库下列表滚动、搜索与排序流畅（虚拟化）。
- 应用启动（到可播放）目标 ≤ 2s（冷启动、小型曲库）。
- 播放进度与 EQ 滑块等高频 UI 更新低频化，避免无谓重绘。

### 8.2 可靠性

- 单个文件解析/播放失败不中断整体扫描或队列。
- 文件被移动、删除或权限变化时给出可读提示，重启扫描后清理索引。
- 崩溃前自动保存播放现场；DB 升级提供迁移而非 destructive。
- 在线服务不可达、限流、超时均不影响本地功能；下载中断清理半截文件。

### 8.3 隐私

- 不上传歌曲、目录、播放历史与播放列表。
- 在线封面/歌手图请求仅发送艺术家与专辑名；在线歌词仅发送标题/艺术家/专辑/时长。
- 在线搜歌请求仅在用户主动搜索时发生。
- 不修改、不删除、不移动用户原始文件。
- 可在设置中整体关闭所有在线能力。

### 8.4 可用性

- 深色沉浸式主题，窗口支持缩放与高 DPI 显示。
- 常用控制（播放/暂停等）支持键盘快捷键与空格。
- 无封面歌曲显示统一默认图，避免空态。

## 9. MVP 验收标准

- 可添加多个音乐文件夹并在重启后保留；重复添加同一路径不产生重复歌曲。
- 只显示已选文件夹及子目录中的有效音乐，目录移除后索引被清理且文件不被删除。
- 播放页封面优先内嵌封面，缺失时显示默认封面。
- 单页布局成立：顶部播放/专辑区 + 底部列表，可切换歌词面板。
- 播放/暂停/上下首/进度拖动/三种模式行为正确。
- 播放列表面板支持双击切歌、移除与清空。
- 媒体键与任务栏缩略图可控制播放。
- 应用重启后恢复有效队列、当前歌曲与进度。
- 列表滚动与搜索在万级曲库下流畅。
- 无明显崩溃、卡顿或主线程阻塞。

## 10. 后续版本建议

1. 自定义播放列表、收藏视图与最近播放。
2. 列表拖拽排序与播放列表导入导出。
3. 睡眠定时器、倍速播放与淡入淡出/无缝播放增强。
4. 歌词/封面/歌手图批量补齐与离线收藏。
5. 主题色自定义与更多皮肤。
6. 与 Android 版共享的元数据/歌词/在线逻辑迁移为可复用核心库。
